# Рацион

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Выбор стека делегирован. Предложение для первой версии — Go, серверные HTML-шаблоны, CSS, небольшой JavaScript и SQLite на Raspberry Pi 5.

## Users

Приложение для одного пользователя, который регулярно питается по одной схеме с фиксированными граммовками. Основной сценарий — открыть с телефона в домашней сети и быстро сверить текущий состав.

## Product Purpose

Хранить актуальный дневной рацион, его состав по приёмам пищи и итоговые калории, белки, жиры и углеводы. Рацион остаётся актуальным, пока пользователь сам его не изменит или не выберет другой.

## Capabilities and Constraints

- Дневные КБЖУ, подытоги каждого приёма пищи, продукты и граммовки порций.
- Именованные сохранённые рационы и явный выбор активного рациона.
- Продукты создаются вручную. Белки, жиры и углеводы вводятся на 100 г, калорийность вычисляется автоматически. Внешний каталог продуктов не используется.
- Изменение БЖУ продукта пересчитывает все сохранённые рационы, которые на него ссылаются.
- Приложение запускается через Docker Compose на Raspberry Pi 5 и используется в домашней сети. SQLite хранится в отдельном томе Docker.

## Product Principles

- Актуальный рацион открывается первым.
- На главном экране сразу видны дневные КБЖУ и калории каждого приёма. БЖУ приёма, продукты и вес открываются по нажатию.
- Состав и граммовки вводятся один раз и редактируются по необходимости.
- В любой момент видно, какой рацион открыт и какой из рационов активен.
